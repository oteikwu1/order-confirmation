# Order Confirmation email

A responsive order confirmation email implemented using MJML framework 

The project is focus on creating clean, modern and responsive transactional 
email that can use to confirm customer's order after a successful purchase 

# Overview 

The is part of email  development portfolio where i focus on designing and 
developing email that renders across all email and screen size both light 
and dark mode and email was implemented using MJML then compile to HTMl and 
test using emailens.dev making sure no compatibility issue and also use mailtools
test both light and dark and also test with Unspam.email to Catch the deliverability issues that send might mail to spam, before subscribers do use mailchimp to sent test email my my Gmail 
and outlook

# Features

- Responsive email layout
- Company's Name
- Confirmation message 
- Order details
- Order Summary
- Shipment detail
